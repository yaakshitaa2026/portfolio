YAAKSHITAA PORTFOLIO WEBSITE

FILES

- style.css: responsive blush/burgundy design

HOW TO OPEN
1. Extract yaakshitaa_portfolio_website.zip.
2. Open index.html in Chrome or Edge.
3. For a smoother local development workflow, open the folder in VS Code and use the Live Server extension.
